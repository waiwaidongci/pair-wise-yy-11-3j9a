# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

给潜水店使用的气瓶充填前端系统：记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面包含待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录。

## 班次交接闭环

- **收班交接**：发起交班时，所有进行中充填（待充填/充填中）连同气瓶、设备、操作员一并生成交接单，移交给接班人。
- **交班门禁**：返工未关闭、气瓶充填完成未签收、清洗单未处理，任一存在即不得交班，界面实时列出阻塞项。
- **接班确认**：接班人确认后当班记录锁定为快照；漏记/错记只能在下一班以"更正单"形式补登，不修改历史快照，已发生充填不受影响。
- **幂等确认**：交接单携带确认令牌，同一班次重复或并发确认只成功一次，后续调用返回"已确认"且状态不变。
- **刷新一致**：队列、交接单、单瓶历史全部持久化到 localStorage，刷新后状态一致。

## 分层结构（规则 / 存储 / 界面分离）

```
src/
  domain/    类型与纯业务规则（交班校验、幂等确认、锁定、更正），无界面无存储
  storage/   localStorage 持久化（读取/保存/重置）
  ui/        界面组件（班次面板、充填队列、登记表单、历史快照、单瓶档案）
  App.tsx    组合层：持有状态、调用规则、同步存储
```
