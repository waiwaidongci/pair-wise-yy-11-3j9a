# hxyfront-62010 潜水气瓶充填记录 · 班次交接闭环

源提示词编号：5

给潜水店使用的气瓶充填前端系统。工作人员可以记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面包含待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录，并在此基础上实现了完整的**班次交接闭环**：

- 收班时，所有进行中充填（待充填 + 充填中）连同气瓶、设备、操作员一并移交接班人；
- 返工未关闭、气瓶未签收或清洗单未处理时不得交班（生成交接单与接班确认两个时点都会校验）；
- 接班确认后当班记录锁定，漏记只能在下一班登记更正，旧班快照永久保留且不影响已发生的充填；
- 同一班次的重复或并发确认只成功一次（存储层单事务提交 + 规则层幂等校验）；
- 队列、交接单和单瓶历史持久化在 localStorage，刷新后一致，多标签页通过 storage 事件同步。

## 分层结构（规则 / 存储 / 界面分离）

```
src/
  domain/
    types.ts    # 领域模型：气瓶、充填记录、班次、交接单、快照、更正
    rules.ts    # 纯函数业务规则：充填生命周期、交班阻塞、幂等确认、更正登记
  data/
    seed.ts     # 演示种子数据
    storage.ts  # localStorage 持久化与单事务提交
  ui/
    useStore.ts # React ↔ 存储桥接（每次 dispatch 从存储读最新状态）
    *.tsx       # 指标栏、充填工作台、登记表单、交接班面板、单瓶历史
  App.tsx       # 界面组装
```
